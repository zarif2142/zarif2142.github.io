# Zarif Ahmed — Portfolio

Static portfolio site hosted on GitHub Pages (`zarif2142.github.io`).

## How to Edit Content
1. Update `index.html` for work experience, projects, or the Now section.
2. Edit individual case studies in `projects/*.html`, work pages in `work/*.html`.
3. Notes live in `notes/*.html`, with an RSS feed at `notes/feed.xml`.
4. Add or replace images in `assets/img/` (covers: 16:10, 1920px masters, with 480/960/1600px JPEG and WebP versions).
5. Drop your latest resume into `assets/Zarif_Ahmed_Resume.pdf`.

## How to Deploy
1. Run `npm test` (Node 22+), then commit and push to the `main` branch.
2. GitHub Pages builds and serves the root directory automatically.
3. Verify live updates at `https://zarif2142.github.io/`.
